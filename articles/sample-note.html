This page exists so you can see the article layout rendered, and so the link in the Articles & Insights list on the home page points somewhere real. Delete it once you publish your first note.

How to publish a new one

Copy articles/_template.html to articles/your-slug.html, replace the {{PLACEHOLDER}} values in the <head>, write the body, then add a row to the article list in index.html. The full steps are in README.md.

Why the metadata matters

When you paste a link into LinkedIn, it fetches the page and reads the og:title, og:description and og:image tags to build the preview card. Those URLs have to be absolute; a relative path like ../assets/portrait.jpg is silently ignored, and you get a bare link with no card.

If you edit an article after sharing it, LinkedIn will keep serving the old cached preview. Their Post Inspector forces a re-scrape.

What the body supports

Headings, paragraphs, lists, links, quotes, images, and code:

  • Inline code and fenced blocks
  • Ordered and unordered lists
  • Images, which scale to the column width automatically
